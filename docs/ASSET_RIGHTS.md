# Publication rights checklist

The technical archive is internally reproducible, but public redistribution
requires decisions by the project owner:

- Select and approve the code license.
- Confirm redistribution terms for every dataset, schema, and derived artifact.
- Confirm whether model outputs may be redistributed under the relevant model
  and dataset terms.
- Add author-approved repository URL/DOI and `CITATION.cff`.
- Remove or anonymize any host-specific or personal metadata if required by the
  chosen public repository policy.

Until these items are resolved, the release status remains an internal reviewer
candidate rather than a licensed public software distribution.
